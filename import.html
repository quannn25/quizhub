Nhập dữ liệu

Nhập danh sách sinh viên và đề thi từ Excel hoặc CSV.

1 Chuẩn bị file theo mẫu

Một file Excel có thể chứa cả sheet SinhVien và DeThi, hoặc dùng từng file CSV riêng. Muốn sửa dữ liệu đang có, hãy xuất ra Excel, sửa rồi nhập lại.

Dùng thử ngay trên trình duyệt này

Sinh viên đăng nhập trên máy này sẽ dùng dữ liệu mới ngay. Hợp để kiểm tra đề hoặc demo trên lớp. Có thể quay về dữ liệu gốc bất kỳ lúc nào.

Cập nhật website cho mọi máy

  1. Tải gói dữ liệu (.zip) và giải nén.
  2. Chép thư mục data vào thư mục website, chọn Thay thế.
  3. Tải lại trang. Nếu dùng GitHub Pages: tải các file mới lên repository.
